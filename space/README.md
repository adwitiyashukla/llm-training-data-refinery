Numbers from a real run of this pipeline over Common Crawl, and a box where you can paste any text and see the verdict of every quality rule. The rules run in your browser with Pyodide, using the same Python code as the pipeline, and language ID uses the fastText lid.176 model through fasttext.wasm.js.

Code and write-up: https://github.com/adwitiyashukla/llm-training-data-refinery
